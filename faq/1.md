# FAQ 1

## Otázky

1. Jaký programovací jazyk a v jaké verzi vaše aplikace využívá?
2. Jaký framework (pokud vůbec) a v jaké verzi je použit pro tvorbu webové aplikace?
3. Jakého správce balíčků používáte v rámci vaší aplikace?
4. Jaký typ databáze aplikace využívá?
5. Jak vypadá connection string do databáze?

## Odpovědi

1. Aplikace je napsána v programovacím jazyce Python. Verze závisí na prostředí, ale běžná podpora je Python 3.11 nebo vyšší.
2. Pro webovou aplikaci je použit framework Flask. Verze je obvykle 3.0 nebo vyšší, pokud projekt používá aktuální verzi Flasku a souvisejících balíčků.
3. Správcem balíčků je pip, standardní nástroj pro Python.
4. Aplikace využívá relační databázi SQLite, uloženou do souboru v místním adresáři projektu.
5. Connection string do SQLite typicky vypadá takto: `sqlite:///cesta/k/souboru/databaze.db`.

4. Přístup uživatelů je řešen jednoduchým přihlášením (`/login`) a session proměnnou `session['logged_in']`. Heslo se ověřuje proti vestavěnému slovníku `AUTH_USERS`, a pokud je přihlášení úspěšné, aplikace nastaví session stav.

5. Hesla jsou v současné implementaci uložena v čistém textu v Python slovníku `AUTH_USERS`. To znamená, že nejsou hashovaná ani zabezpečená, což je jednoduché, ale není to produkční řešení.

6. Ochrana operací pro přihlášené uživatele je zajištěna dekorátorem `@login_required` nad jednotlivými routami. Například pro úpravu a smazání záznamu:

```python
@app.route('/manage/edit/<int:record_id>', methods=['GET', 'POST'])
@login_required
def edit_record(record_id):
    ...

@app.route('/manage/delete/<int:record_id>', methods=['POST'])
@login_required
def delete_record(record_id):
    conn = get_db()
    conn.execute('DELETE FROM bird_records WHERE id = ?', (record_id,))
    conn.commit()
    conn.close()
    flash('Záznam byl odstraněn.', 'success')
    return redirect(url_for('manage_records'))
```
